# Sociolla Interview - Backend

This is the backend for the Sociolla interview project. It uses **Express.js** and **MongoDB** to provide APIs for the React Native application.  

## Features
- Provides a list of promos via API (`/promos`)

## Technology Stack
- Node.js
- MongoDB

## Setup & Run
1. Clone the repository:
```bash
git clone [backend-repo-link]
cd [backend-folder-name]
```
2. Install the dependency
```bash
npm install
```
4. Run the server
```bash
npm start
```
